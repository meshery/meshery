# Security Policy

## Reporting a Vulnerability

We are very grateful to the security researchers and users that report back Meshery security vulnerabilities. We investigate every report thoroughly.

To report a vulnerability privately, please submit a report through GitHub's [Private Vulnerability Reporting](https://github.com/meshery/meshery/security/advisories/new) or email the private [security@meshery.io](mailto:security@meshery.io) mailing list.

For details of published vulnerabilities, see [security vulnerabilities](https://docs.meshery.io/project/security-vulnerabilities) in Meshery Docs.

## Supported Versions

See [release cadence](https://docs.meshery.io/project/contributing/build-and-release#release-cadence) in Meshery Docs for the support schedule.
