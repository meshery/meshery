###  MeshModel Component Icon SVGs
- Place your new MeshModel Component icon SVGs in this folder
- You can either drag and drop the SVG file inside this folder directly from the browser and create a PR or fork the repo and add the file inside the folder then make a PR

### Liquid glass Workflow icon variants

- `argo-workflows-workflow-white.svg` uses white gradients with varying opacity. Use it only on dark or sufficiently contrasting colored surfaces, never on white or pale backgrounds.
- Select the variant for the actual surface, rather than the page theme alone. A light-mode page can contain a dark surface, and a dark-mode page can contain a light surface.

These static SVG assets do not switch variants automatically. The consuming UI must select a suitable variant and re-evaluate that selection when the theme or surface background changes.
