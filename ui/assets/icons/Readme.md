###  MeshModel Component Icon SVGs
- Place your new MeshModel Component icon SVGs in this folder
- You can either drag and drop the SVG file inside this folder directly from the browser and create a PR or fork the repo and add the file inside the folder then make a PR

### Workflow icon variants

- Use `argo-workflows-workflow-color.svg` on light backgrounds. Its `#243746` strokes and fills require a light surface for contrast.
- Use `argo-workflows-workflow-white.svg` on dark backgrounds.

The consuming UI must select the appropriate variant for the actual background, including when the theme changes. These static SVG assets do not switch variants automatically.
