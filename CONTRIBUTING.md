# Contributing to Meshery 

Please do! Thank you for your help in improving Meshery! :balloon:

Functional pull requests must be pushed through no-mistakes (`no-mistakes axi run --intent "<goal>"` or `git push no-mistakes <branch>`), which writes the `## Pipeline` attestation the merge check requires. Website-only, documentation-only, and CI-only pull requests are exempt. At most three pipeline runs per pull request; if the change is not green after three, stop and ask a maintainer.

Find the complete set of contributor guides at https://docs.meshery.io/project/contributing
