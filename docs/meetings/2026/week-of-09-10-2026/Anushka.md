## Open Source

I recently started contributing to Meshery and submitted my first pull request.

### My First Meshery Contribution

**Issue:** [#21878](https://github.com/meshery/meshery/issues/21878)

**PR:** [Return 400 for malformed event filter query parameters](https://github.com/meshery/meshery/pull/new/fix/malformed-event-filter)

The contribution fixes an issue where malformed JSON in event filter query parameters could be ignored by the Meshery server.

I added a regression test and updated the handler so that malformed filters return `400 Bad Request` and the provider is not called.

I'm looking forward to learning more about the Meshery codebase, contributing to more issues, and getting involved with the community.
