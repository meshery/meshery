Section pages:

- [KubeCon Workshop: Build Your Own Meshery Model and Design](/pr-preview/pr-23262/guides/tutorials/playground/kubecon-build-your-own-model-and-design/): A 90-minute Meshery Playground workshop in which every attendee creates their own model and a design that uses it.
- [Deploy AWS EC2 Instances with Meshery](/pr-preview/pr-23262/guides/tutorials/aws/deploy-aws-ec2-instances-with-meshery/): Deploy an EC2 instance and its VPC from Meshery, using AWS Controllers for Kubernetes (ACK) and designs from the Meshery Catalog.
- [Deploy Azure resources with Meshery](/pr-preview/pr-23262/guides/tutorials/azure/deploy-azure-resources-with-meshery/): Install Azure Service Operator in your cluster and deploy Azure resources, such as Storage Accounts and Key Vaults, from a Meshery Design.
- [Deploy Azure Storage Account with Meshery](/pr-preview/pr-23262/guides/tutorials/azure/deploy-azure-storage-account-with-meshery/): Install Azure Service Operator in your cluster and deploy an Azure Storage Account from a Meshery Design.
- [Embedding a Meshery Design in a WordPress Post](/pr-preview/pr-23262/guides/tutorials/wordpress/embedding-meshery-design-in-wordpress/): Embed an interactive Meshery Design in a WordPress post, using the embed export from Kanvas.
- [Playground](/pr-preview/pr-23262/guides/tutorials/playground/): Hands-on tutorials and workshops that run entirely in the Meshery Playground.
- [Publishing Meshery Designs to Artifact Hub](/pr-preview/pr-23262/guides/tutorials/artifacthub/publish-to-artifacthub/): Export a Meshery Design as an OCI image and publish it to an Artifact Hub repository.
- [Tutorials](/pr-preview/pr-23262/guides/tutorials/): Explore the tutorials to learn how to use Meshery for collaboratively managing infrastructure.
