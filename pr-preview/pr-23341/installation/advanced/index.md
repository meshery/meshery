# Advanced Configuration

> Advanced installation and runtime configuration topics for Meshery.

These pages cover configuration beyond a default installation: the environment variables Meshery Server reads, running Meshery in GitHub Codespaces, and running more or fewer Meshery Adapters.

---

Section pages:

- [Codespaces](/docs-preview/pr-preview/pr-23341/installation/advanced/codespaces/): Build and contribute to Meshery using GitHub Codespaces
- [Server Environment Variables](/docs-preview/pr-preview/pr-23341/installation/advanced/environment-variables/): Installation and runtime configuration reference for the environment variables consumed by Meshery Server.
- [Using Multiple Adapters](/docs-preview/pr-preview/pr-23341/installation/advanced/multiple-adapters/): Choose which Meshery Adapters to run, run more than one instance of an adapter, or run none at all.
