# Extensions

> Meshery architecture is extensible. Meshery provides several extension points for working with different cloud native infrastructure via adapters, load generators and providers.

---

LLMS index: [llms.txt](/docs-preview/pr-preview/pr-23341/llms.txt)

---

Visit [https://meshery.io/extensions](https://meshery.io/extensions) to browse the complete collection of Meshery extensions.

---

Section pages:

- [Helm Snapshot](/docs-preview/pr-preview/pr-23341/extensions/extensions/helm-snapshot/): Helm CLI plugin to visually render a snapshot of your Helm charts.
- [Kanvas](/docs-preview/pr-preview/pr-23341/extensions/extensions/kanvas/): Collaborative cloud native visual designer to design and manage infrastructure and applications.
- [kubectl MeshSync Snapshot](/docs-preview/pr-preview/pr-23341/extensions/extensions/kubectl-meshsync-snapshot/): A native kubectl plugin for conveniently synchronizing the state of your cluster with Meshery Server.
- [mesheryctl-axi](/docs-preview/pr-preview/pr-23341/extensions/extensions/mesheryctl-axi/): An agent-ergonomic AXI wrapper around mesheryctl - token-efficient TOON output, always non-interactive, with help[] next-step suggestions.
- [Shape Builder](/docs-preview/pr-preview/pr-23341/extensions/extensions/shape-builder/): Create custom polygon shapes for Meshery components.
