ErrOpenDatabaseFileCode-1398

Component: component / meshery-server
Code: meshery-server-1398 (ErrOpenDatabaseFileCode-1398)
Severity: Alert

Short description

The database does not exist or you don't have enough permission to access it

Long description

Probable cause

  • mesherydb.sql is missing or not readable by the server process

Suggested remediation

  • Verify that mesherydb.sql exists under ~/.meshery/config and that the server process can read it
